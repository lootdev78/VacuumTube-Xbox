# VacuumTube Xbox 1.1.0

UWP-/WinUI-2-WebView2-App für Xbox Dev Mode. Die ausführbare Laufzeit liegt unter `Assets/ExtensionRuntime`; native Dienste liegen unter `Services`.

Die App enthält die Xbox-adaptierten Funktionen aus VacuumTube, youtube-webos und TizenTube, nicht deren vollständige Quellbäume. Details: `../Docs/FEATURE-MATRIX.md`.

Build über `../Scripts/Build-Debug-MSIX.ps1`. Ein echter MSIX-/Xbox-Test wurde in der bereitstellenden Linux-Umgebung nicht durchgeführt.
